# 🚆 Railway Ticket Booking System Using Python

## 📌 Project Overview
The Railway Ticket Booking System is a console-based application developed using Python and Object-Oriented Programming (OOP) concepts.

This application allows users to register, log in, view available trains, book railway tickets, enter passenger details, and generate PNR numbers.

## ✨ Features
- User Registration and Login
- Display Available Train Details
- Train Selection and Ticket Booking
- Multiple Passenger Booking
- Passenger Information Management
- Automatic PNR Number Generation
- Input Validation and Exception Handling
- Automatic Seat Availability Updates
- Individual Passenger Ticket Display
